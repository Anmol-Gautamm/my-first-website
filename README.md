# 🐦 Flappy Bird Arcade

An interactive, feature-rich Flappy Bird Arcade game built using **HTML5 Canvas**, **CSS3**, and **Vanilla JavaScript**.

🎮 **[Play Live Demo](https://anmol-gautamm.github.io/Flappy-Bird-/)**

---

## ✨ Features

- 🎮 **Smooth Physics & Gameplay**: Accurate velocity, gravity, collision detection, and rotation.
- ⚡ **3 Difficulty Levels**:
  - 🟢 **Easy**: Relaxed pipe speed & wider gaps
  - 🟡 **Normal**: Classic arcade challenge
  - 🔴 **Hard**: Fast-paced, tight obstacles for pros
- 📱 **Fully Responsive**: Optimized for desktop monitors, tablets, and mobile devices (touch controls supported).
- 🔊 **Audio System**: Sound effects for flapping, scoring, hit sound, and mute toggle.
- ⏯️ **Pause & Restart**: Easily pause (`P`) or quick restart (`R`) anytime.
- 🎨 **Arcade Aesthetics**: Retro pixel styling with dynamic UI overlays and smooth animations.

---

## 🕹️ Controls

| Action | Keyboard | Mouse / Touch |
| :--- | :--- | :--- |
| **Flap / Jump** | `Space` / `Up Arrow` | Click / Tap canvas |
| **Change Difficulty** | `1` (Easy), `2` (Normal), `3` (Hard) | Click difficulty buttons |
| **Pause / Resume** | `P` | Click ⏸️ button |
| **Toggle Sound** | `M` | Click 🔊 button |
| **Restart Game** | `R` | Click Restart button on game over |

## 🛠️ Built With

* **HTML5 Canvas**: High-performance 2D game rendering.
* **CSS3**: Glassmorphism overlays, animations, and custom web fonts (`Outfit`, `Press Start 2P`).
* **JavaScript (ES6+)**: Object-oriented game engine, state management, and event handling.

## 💻 Local Setup & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Anmol-Gautamm/my-first-website.git
   ```

2. **Open the project:**
   Navigate into the project directory and open `index.html` in your web browser:
   ```bash
   cd my-first-website
   start index.html  # On Windows
   ```
